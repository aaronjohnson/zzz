# zzz - Sleep Hygiene Tracker

A simple Flutter app for tracking daily sleep hygiene habits. Like a digital clipboard for better sleep.

## Features

- **Weekly Chart** - Check off daily sleep hygiene habits at a glance
- **Day Detail** - Longer descriptions with motivation for each habit
- **12 Default Habits** - Evidence-based sleep hygiene recommendations
- **Local Storage** - SQLite database, all data stays on your device

## Habits Tracked

| Category | Habit |
|----------|-------|
| Timing | Consistent bedtime, Consistent wake time |
| Environment | Dark room, Cool temperature, Phone out of reach |
| Substances | No late caffeine, Limited alcohol |
| Wind-down | Screen-free hour, Relaxation routine |
| Daytime | Morning light, Exercise, Limited naps |

## Privacy

Your sleep data never leaves your device. No accounts, no sync, no telemetry.

See [PRIVACY.md](PRIVACY.md) for the full privacy architecture.
